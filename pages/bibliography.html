Annotated Bibliography

Web Development

These resources relate to the coding and development of the website. I used them to learn popular web development technologies such as Canvas API, TypeScript, and Vite. I used MDN as a general resource for various web development topics, and I used the specific technology documentation pages for specific and advanced principles.

  • “Canvas API.” MDN. https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API.
  • MDN. https://developer.mozilla.org/en-US/.
  • “TypeScript Documentation.” TypeScript. https://www.typescriptlang.org/docs/.
  • Vite. https://vite.dev/.

Architectural Design Patterns

These resources relate to the architectural design of the website’s code. I used them to learn popular design patterns such as model-view-controller, state pattern, entity component system, and observer pattern. The Game Programming Patterns book was especially useful, as it contained information about the state pattern and many other patterns, as well as performance optimization tips.

  • “Entity Component System.” UMLBoard. https://www.umlboard.com/design-patterns/entity-component-system.html.
  • “MVC Framework Introduction. GeeksforGeeks. https://www.geeksforgeeks.org/software-engineering/mvc-framework-introduction/.
  • Nystrom, Robert. Game Programming Patterns. Genever Benning, 2014.
  • “Observer Pattern.” patterns. https://www.patterns.dev/vanilla/observer-pattern/.
